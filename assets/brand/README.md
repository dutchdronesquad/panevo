# Panevo Brand Assets

This folder contains Panevo brand assets for README, documentation, website, GitHub, and general project presentation.

## Files

- `panevo-logo-color-lightbg.svg`: full color logo for light backgrounds.
- `panevo-logo-color-lightbg.png`: PNG export of the light-background logo.
- `panevo-logo-color-darkbg.svg`: full color logo for dark backgrounds.
- `panevo-logo-color-darkbg.png`: PNG export of the dark-background logo.
- `panevo-icon-color.svg`: icon-only version.
- `panevo-icon-color.png`: PNG export of the icon-only version.

## Usage

- Use SVG assets in README and documentation where possible.
- Use the dark-background logo on dark surfaces.
- Use the light-background logo on light surfaces.
- Use the icon for small avatars, favicons, and compact brand placement.

## App Icons

Packaged Electron app icons should live in a separate `assets/app-icon` folder later. That folder can contain generated platform-specific assets such as `.icns`, `.ico`, and required PNG sizes.
